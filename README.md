# BedLauncher

Launcher simples para o Minecraft Bedrock oficial no Android.

- Detecta o jogo instalado e mostra a versão
- Abre o jogo com um toque
- Importa .mcworld, .mcpack, .mcaddon e .mctemplate

Requer o Minecraft Bedrock oficial instalado. Projeto independente, sem vínculo com a Mojang ou a Microsoft.
